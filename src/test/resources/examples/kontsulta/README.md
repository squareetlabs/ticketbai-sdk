# Ejemplos de Kontsulta

| Fichero | Origen |
|---|---|
| `araba/consulta-paginada.xml`, `araba/ultima-factura.xml` | Ejemplos oficiales de la Diputación Foral de Álava («Ejemplos de XML», documentación técnica de Kontsulta). |
| `gipuzkoa/kontsultaV1.0.xml`, `gipuzkoa/kontsultaUltimaFacturaV1.0.xml`, `gipuzkoa/respuesta_kontsultaV1.0.xml` | Ejemplos oficiales de la Diputación Foral de Gipuzkoa («Kontsulta XML», entorno de pruebas, 2022). La respuesta lleva el nombre de cada campo como valor: sirve para la estructura, no para leer datos. |
| `araba/respuesta-sdk.xml`, `gipuzkoa/respuesta-sdk.xml` | **Escritos para el SDK** a partir de los XSD (1.2.3 de Álava y 1.0 de Gipuzkoa), porque no hay respuestas oficiales con datos. La respuesta de Álava cumple su XSD. Las firmas son inventadas; los códigos TicketBAI tienen un CRC válido. |
